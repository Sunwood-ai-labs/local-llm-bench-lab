# リポジトリ名

採用名は `local-llm-bench-lab` です。

候補としては以下も考えられました。

- `apple-silicon-llm-bench`: わかりやすいが、Apple Silicon 色が強く他環境へ広げにくい。
- `gemma4-bench-lab`: 初期実験には合うが、別モデルを足すと狭い。
- `local-ai-bench-lab`: 対象は広がるが、LLM 焦点が弱い。

目的はローカル LLM の runtime とモデル設定を再現可能に比較することです。`local-llm-bench-lab` はモデル非依存で、環境構築や高速化の実験も含めやすい名前です。
