# Repository name

採用名: `local-llm-bench-lab`

候補としては以下も考えられました。

- `apple-silicon-llm-bench`: Apple Silicon 色が強く、他環境へ広げにくい。
- `gemma4-bench-lab`: 今回の実験には合うが、別モデルを足すと狭い。
- `local-ai-bench-lab`: 画像・音声なども含められるが、LLM焦点が弱い。

今回の目的は「このPCでローカルLLMをいろいろ比較する」ことなので、モデル非依存で分かりやすい `local-llm-bench-lab` を採用しました。
