# Support

Use GitHub Issues for reproducibility questions, benchmark result additions, and documentation corrections.

Before opening an issue, please include:

- the command you ran
- the backend and model name
- macOS version and Apple Silicon chip when relevant
- whether model files are local, cached, or served through a runtime such as Ollama
- the smallest result snippet needed to understand the problem

Do not include secrets, API tokens, private prompts, or heavyweight model files.
